# TM linear_attn 逐通道衰减(KDA 形态)代价盘点

日期:2026-11-17 | 性质:只读调研,未改任何代码 | 上游文档:`benchmark/gdn_option_a_notes.md`(方案 A)、`benchmark/batch2_benchmarks_report.md`(批 2/零拷贝)、`benchmark/b3_01_bridge_report.md`(桥层)。

## 0. 结论速览

1. **语义判定(问 1):不等价,且现状是"TM 不支持"而非"TM 近似在跑"。** PT GLM-5.3 = 逐 key 通道衰减 + 低秩门控 + dt_bias\[H·K\] + lower_bound 钳位 + sigmoid 输出门(`glm5_next.py:724` `Kda()`);TM `GatedDeltaNetLayer` = per-head 标量衰减(`gated_delta_net_kernels.cu:19-50`)+ SiLU 输出门硬编码(`gated_delta_net_kernels.cu:192-193`),数学结构不可映射(diag(exp(g\[h,k\])) 作用于 K 维 vs 标量乘整块 \[K,V\])。**TM python 注册表根本没有 glm5_next**(`lmdeploy/turbomind/models/__init__.py:1-13`),语境前提"TM 用 GDN 跑 GLM-5.3"在本 tree 不成立——不存在线上数值错误,但 TM 引擎当前无法加载该模型;强行映射则必错。
2. **kernel 改造盘点(问 2):decode 侧 S+ 级(约 6 文件,数天);prefill 侧 sm_90/sm_120 fused chunk 各 L 级;pre_sm90 chunked 建议不做**(SM86 上 TM chunked 已证输 fla 0.61–0.65×);conv 与量化路径 S≈0。
3. **模型层(问 3):L–XL,且被非 decay 因素硬阻断**——GLM-5.3 全注意力层 = DSA/MLA+KPool(`configurations/glm5_next.py:14-16`),TM 引擎无 MLA/DSA 设施;另有低秩门控拓扑不适配 TM `fuse_gdn` 的 `[Q|K|V|Z|B|A]` 单槽融合(`builders/deltanet.py:32-46`)。
4. **解锁收益(问 4):现实解锁面 = GLM-5.3 的 34 个 KDA 层 decode(经 TM kernel 嫁接进 PT 引擎)**;本 repo 的 Kimi-K2.5 是全注意力 MoE(`kimi_k25.py:15-16`,`kimi_k2_language.py` 无 KDA 命中),无解锁面;Qwen3.5-Next/interns2_mobius 是 per-head 原生(`qwen3_5.py:479-487`),无需本改造但须保向后兼容。
5. **总评(问 5):切线 1(decode-only + 零拷贝组合)先行**,S+ 级即可让 GLM-5.3 decode 受益且回滚成本最低;sm_90/sm_120 通道衰减单独立项、以 H200 对 fla `chunk_kda` 复测为门槛;TM 原生 GLM-5.3 与 decay 解耦。

## 1. 语义核实(问 1):PT KDA vs TM GatedDeltaNetLayer

| 语义项        | PT GLM-5.3(`Glm5NextLinearAttention` + `Kda`)                                                                                              | TM `GatedDeltaNetLayer`                                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 衰减 g 形态   | 逐 key 通道 `[T, H, K]`(raw_gate = `g_b_proj` 输出 H·K 宽,`glm5_next.py:681-690`)                                                          | per-(token,head) 标量 `[T, H]`(切槽宽 = value_heads,`GatedDeltaNetLayer.cc:379-387`)                                          |
| 门控来源      | 低秩:`fg_a_proj` \[hidden→2·head_dim\](TP 复制,`glm5_next.py:663-671`)+ `fg_b_proj` batched [head_dim→H·K](`glm5_next.py:672-690`)         | `in_proj_all` 直投影切槽(GDNLayer.cc:379-388)                                                                                 |
| g 参数        | A_log [H](`glm5_next.py:694-697`)+ dt_bias [H·K](`glm5_next.py:698-701`)                                                                   | A_log \[H\]、dt_bias \[H\](`gated_delta_net_kernels.cu:45-48`,`hv = A_log.size()` :60)                                        |
| 钳位          | lower_bound(默认 -5.0)闭式 `g = lower_bound/(1+exp(-exp(A_log)·softplus))` ∈ (lower_bound, 0\](`kernels/cuda/gated_delta_rule.py:550-552`) | **无钳位**                                                                                                                    |
| beta          | per-head 标量(`glm5_next.py:653-659` b_proj → sigmoid)                                                                                     | per-head 标量(`gated_delta_net_kernels.cu:43`)——此项一致                                                                      |
| 输出门        | RMSNorm × **sigmoid**(`glm5_next.py:705-708`)                                                                                              | RMSNorm × **SiLU 硬编码**(`gated_delta_net_kernels.cu:192-193`)                                                               |
| decode kernel | TileLang 共享 kernel,channelwise g 硬依赖 V-first 转置布局(`gated_delta_rule.py:736-747`,调用 `backends/cuda/kda.py:145-151,299-300`)      | pre_sm90/sm_90/sm_120 recurrent 全部标量 `expf(g[seq·stride+head])`(`pre_sm90/recurrent.cu:74,163`;`sm_120/recurrent.cu:352`) |
| prefill       | fla `chunk_kda`(`backends/cuda/kda.py:47,304-319`)+ indexed `chunk_kda` 变体(`:365-368`)                                                   | pre_sm90 chunked / sm_90 / sm_120 fused chunk,标量 g_cumsum(`kernel/plan.cc:109-115`)                                         |

**判定:不等价 → TM 侧为"不支持"。** 修正语境前提:`lmdeploy/turbomind/models/__init__.py:1-13` 注册的 GDN 模型仅 qwen3_5(`qwen3_5.py:187` DeltaNetBuilder)与 interns2_mobius(继承 Qwen3_5Model,`interns2_mobius.py:192`,3×DeltaNet+1×Attn 循环 :18)。GLM-5.3(34 KDA + 11 MLA/DSA)无 TM 注册路径,**不存在"两引擎跑同一模型数值不一致"的现网风险**;风险形态是"无法服务 + 未来误接即错"。强行 per-head 均值退化:每头衰减自由度 64 → 8192,非精度损失而是数学结构不同 `[INFERENCE:无 checkpoint 统计,不量化幅度]`。附加失配(即便补了通道衰减也挡着):sigmoid vs SiLU 输出门、低秩门控拓扑、lower_bound 钳位。

## 2. kernel 路径改造盘点(问 2)

设计前提建议:**TM kernel 继续消费"已物化"的 g**(exp 前的负 log decay),门控物化(A_log/dt_bias/lower_bound)放在 ComputeBetaG 或 PT 侧 `kda_gate_fwd`——kernel 改动收敛为"g 索引从 \[T,H\] 变 \[T,H·K\] + 按 k 通道取因子",beta 维持标量不动。

## 3. 模型层改造清单(问 3,仅"TM 原生承载"需要)

1. `DeltaNetConfig`/`DeltaNetWeight`(`models/delta_net_weight.h:14-27,55-58`):加 decay_mode 标志;dt_bias 尺寸 H·K;A_log 保持 \[H\](`delta_net_weight.cc:27-28` fp32 约束不变)。
2. `GatedDeltaNetLayer.cc`:`gate_stride_` 拆 beta/g 双 stride(:92,:278-279);beta/g 缓冲与 layout(:381-384,g 缓冲 ×K fp32);`decay_gate_offset` 切宽 H·K(:379,:387);recurrent gate layout(:449-456);`unified_decoder.cc:58-111` 权重收集不变。
3. `builders/deltanet.py`:`fuse_gdn` [Q|K|V|Z|B|A](:32-46)**不适配** GLM 低秩门控(fg_a \[hidden→2·head_dim\] TP 复制 + f_b/g_b \[head_dim→H·K\])→ 需新增 weight 槽与第二投影;`add_scalar_params`(:93-97)dt_bias 传递可用。
4. TM 侧 glm5_next 模型类 + config builder(镜像 `lmdeploy/turbomind/models/qwen3_5.py` 模式)。
5. **硬阻断(与 decay 无关)**:GLM-5.3 全注意力层 = `deepseek_sparse_attention`/MLA+KPool(`configurations/glm5_next.py:14-16,278-307`;`glm5_next.py:755+` Glm5NextSparseAttention),TM 引擎注册表(`lmdeploy/turbomind/models/__init__.py:1-13`)无 MLA/DSA/KPool 设施 → TM 原生 GLM-5.3 的主缺口在注意力侧,不在衰减。

## 5. 总评(问 5):两条切线

**切线 1:decode-only + 零拷贝直读组合(建议先行)** — pre_sm90 recurrent 增"kVK + 通道衰减 + per-channel g"变体(6 文件:S+ 级,数天 `[估算]`),ComputeBetaG 通道变体(S);`state_ptrs` 直指 PT indexed 池行(vk 直读已证损失 0.90–1.31×、B=32 反超,`batch2_benchmarks_report.md` 方案 B 节);GLM-5.3 decode 立即受益;prefill 留 fla(与批 2 判定一致);回滚=删变体,per-head 默认路径零改动 → **低**。

**切线 2:全路径一步到位** — + sm_90 与 sm_120 fused chunk 各 L(2 架构 × dtype×CP/TP 验证矩阵,g_cumsum workspace ×128 `[估算]`)+ pre_sm90 chunked M(负收益区)+ 模型层 L–XL(且被 MLA/DSA 阻断);数周–月级 `[估算]`。sm_90/sm_120 fused chunk 相对 fla `chunk_kda` 的胜率无本机数据(SM86 测不了),立项依据不足。

**建议**:切线 1 立项;sm_90/sm_120 通道衰减单独立项并以 H200 对 fla 复测为门槛;TM 原生 GLM-5.3(模型层+MLA/DSA/KPool)与 decay 解耦,不进本票。
